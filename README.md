# Aplikasi Kuis Pilihan Berganda: Flutriva
Flutriva adalah aplikasi kuis pilihan ganda berbasis Flutter untuk menguji
pemahaman dasar tentang Flutter dan Dart. Pengguna memasukkan nama, menjawab
serangkaian soal, lalu melihat skor akhir beserta pembahasan setiap soal.<br>

## Fitur-fitur
- Input nama pengguna dengan validasi (wajib diisi, minimal 2 karakter).<br>
- Kuis pilihan ganda 8 soal dengan indikator progres dan persentase.<br>
- Navigasi soal sebelumnya/selanjutnya; jawaban dapat diubah sebelum selesai.<br>
- Skor akhir dengan pesan sesuai capaian.<br>
- Pembahasan per soal: opsi benar/salah ditandai warna, disertai penjelasan mengapa jawaban pengguna salah dan mengapa jawaban yang benar itu benar.<br>
- Fitur "Lanjutkan" untuk melanjutkan kuis yang belum selesai dan "Ulangi Kuis".<br>
- State management dengan Provider: progres tidak hilang saat layar dirotasi atau berpindah halaman.<br>
- Tampilan responsive dan adaptive: ukuran elemen dinamis mengikuti layar layout berubah menjadi 2 kolom pada tablet, browser, atau layar lebar.<br>
- Data soal bersifat lokal (dummy), tanpa database.<br>
